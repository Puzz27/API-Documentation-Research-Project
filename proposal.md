Final Project Research Proposal

What ways did api documentation change before/during/after the post api era of web data? 
Did api documentations change in similar ways to each other?
Did api documents change with each other like a domino effect?


I want to look into the shape, size, and keywords contained within api documentation across various major platforms. Specifically I’m curious about how the post api era of the internet changed these documentations, for the ones that still exist. 

Web data Scientists would probably be the biggest stakeholder for this project as they rely on these APIs and their documentation to do research. People building tools, apps, and large scale data projects with these APIs would also be key stakeholders, as APIs are the only way they can get access to the data they need for these applications. I think platform users could also benefit from this research, as it would show how access to their own personal data has changed. 

I’d expect to find a shift in the page length of the API documentation. I’m also expecting to find certain keywords that appear on API documents after a certain timeframe. It would be upsetting and surprising to find there is no correlation, and nothing concrete changes about the documentation.

For this project I will use the Wayback Machine’s public CDX API. I’m planning on being able to capture static pages from API calls, then using those pages for research. I will use concepts I’ve learned mainly from Chapter 7 (Archived web pages & the Wayback Machine) to conduct research. Since I will be collecting static pages I will also be using methods from Chapter 6 (Parsing static web pages). I want to collect documentation from a few different major platforms like X and Reddit, but I’m also curious about how or if smaller APIs also changed. I will probably find documentation for a few smaller APIs as well, and see if any significant change occurred.
