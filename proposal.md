Project description: By using data collection and parsing methods learned in class, design a research question and explore its potential answers and solutions. 

Main Idea:

Research ways in which the API documentation has changed within Meta’s Graph API, and how the API itself has changed. 

I want to look into the shape, size, and keywords contained within Meta’s Graph API. Specifically I’m curious about how the post API era of the internet changed the documentations, for the ones that still exist. 

Web data Scientists would probably be the biggest stakeholder for this project as they rely on these APIs and their documentation to do research. People building tools, apps, and large scale data projects with these APIs would also be key stakeholders, as APIs are the only way they can get access to the data they need for these applications. I think platform users could also benefit from this research, as it would show how access to their own personal data has changed. 

I’d expect to find a shift in the page length of the API documentation. I’m also expecting to find certain keywords that appear on API documents after a certain timeframe. I also expect bigger updates to have more changes to specific endpoints, and especially during 2018 I expect a lot of changes across the entire API.

For this project I will use the Wayback Machine’s public CDX API. I’m planning on being able to capture static pages from API calls, then using those pages for research. I will use concepts I’ve learned mainly from Chapter 7 (Archived web pages & the Wayback Machine) to conduct research. Since I will be collecting static pages I will also be using methods from Chapter 6 (Parsing static web pages). I will also be scraping directly from developers.facebook.com as this site contains all of the Graph Api’s Changelogs.
